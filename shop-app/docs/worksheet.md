# 🛒 ショッピングサイトを作ろう！ ワークシート（生徒用）

ようこそ！ 君は今日、これから **本物そっくりのインターネット通販サイト** を
自分の手で完成させていきます。

難しいプログラムは、ほとんど先生が用意してあります。
君がやるのは「**画面に何を出すか**」を決めている部分を、自分で書き込むことです。

> 📸 （ここに完成イメージのスクリーンショットを入れる）

---

## 0. 準備 — まずは動かしてみよう

### サイトを起動する
1. `shop-app` フォルダの中の **`run.bat`** をダブルクリックします。
2. 黒い画面（コマンドプロンプト）が開いて、こんな文字が出たら成功です。
   ```
   ショッピングサイトが起動しました！
   ブラウザで以下のURLを開いてください:
     http://localhost:3000
   ```
3. ブラウザ（Edge や Chrome）を開いて、アドレスバーに
   **`http://localhost:3000`** と入力します。
4. お店のトップページが出てきたら準備完了！🎉

> ⚠️ 黒い画面は **閉じないで** ください。閉じるとお店が止まります。

### コードを編集する（VSCode）
- ファイルは **VSCode** で開いて編集します。
- 直したら **保存（Ctrl + S）** → ブラウザを **更新（F5）** すると、変化が画面に出ます。
- 「編集 → 保存 → ブラウザ更新」。この繰り返しが基本です。

### この課題のルール
- 編集するのは、各ステップで指定された **ファイルだけ** です。
- 文章の中の **`______`** は「**ここに自分で書き込む場所**」という意味です。
- 間違えても、壊れません。何度でもやり直してOK！

## 🔰 EJS の基本ルール（これだけ覚えればOK）

このサイトの画面は **EJS** という仕組みでできています。覚えるのは2つだけ。

| 書き方 | 意味 | 例 |
|--------|------|-----|
| `<%= ○○ %>` | ○○の中身を **画面に表示する** | `<%= item.name %>` → 商品名が出る |
| `<% ～ %>` | 表示はしないで **計算や条件** をする | `<% if (...) { %>` |

商品データは `item` という箱に入っていて、中身はこうなっています👇

| 書き方 | 出てくるもの |
|--------|------------|
| `item.name` | 商品名（例：ギター） |
| `item.price` | 値段（例：30000） |
| `item.image` | 画像のファイル名（例：guitar） |
| `item.stock` | 在庫の数（例：10） |
| `item.code` | 商品番号（例：1） |
| `item.description` | 商品の説明文（詳細ページに出る） |

## Step 1 🗂️ 商品を登録しよう（増やす・減らす）

お店に並べる商品を登録します。やり方は2つ。

### やり方① 管理画面のフォームから
URL `http://localhost:3000/step1`（ナビの ⚙️商品管理）を開きます。
左のフォームに **商品名・価格・画像・商品説明** を入れて「追加する」を押すと、
すぐに商品が増えます。要らない商品は右の一覧の 🗑️ で消せます。

### やり方② コードで最初の品ぞろえを決める（`db/seed.js`）
**編集するファイル：`db/seed.js`**

このファイルには「お店に最初から並べておく商品」が書いてあります。今は3つです。

```js
db.run(`INSERT INTO item (name, price, image, stock, description) VALUES ('ギター', 30000, 'guitar', 10, '初心者にもやさしいギター。')`);
```

1行が「商品1つ」です。`('商品名', 値段, '画像名', 在庫数, '説明文')` の順に書きます。

#### 課題1-A：商品を1つ増やす
下の `______` を自分で決めて、新しい行を **1行追加** しよう。
使える画像名の一覧は、このシートの一番下にあります。

```js
db.run(`INSERT INTO item (name, price, image, stock, description) VALUES ('______', ______, '______', 10, '______')`);
```

#### 課題1-B：商品を1つ減らす
要らない商品の行を **1行消して** みよう。（行の先頭にカーソル → その行をまるごと削除）

### ✅ 確認の仕方（大事）
`seed.js` を変えたら、**`run.bat` をいったん閉じて、`run_reset.bat`（先生が用意）で起動し直す**と、
変えたデータで作り直せます。
> `seed.js` は「最初の1回」だけ読まれるので、普通の `run.bat` では反映されません。
> （フォームからの追加は、その場ですぐ反映されます。）

トップページ（`/`）や ⚙️商品管理 の画面で、商品が増えた・減ったか確認しよう。

## Step 2 🖼️ カードで並べて、詳細ページを作ろう（穴埋め）

**編集するファイル：`views/partials/product_card.ejs`**（商品カードの共通パーツ）

URL `http://localhost:3000/step2` は、商品を大きなカードで並べる画面です。
カードの「値段」と「在庫」を完成させよう。カードの「詳細を見る」を押すと
**商品詳細ページ（`/item/番号`）** が開きます。

> ✨ **大事：** このカードは「共通パーツ」です。ここを直すと、
> Step2 だけでなく **本番のお店（`/shop`）やトップページのカードも同時に変わります**。
> 自分が作った画面が、そのままお店で使われるということ！

### 課題2-A：値段を出す
```html
<p class="card-text text-primary fs-5 fw-bold mb-1">
    ¥<%= ______ %>
</p>
```
💡ヒント：値段は `item.price`。`.toLocaleString()` を後ろに付けると `30,000` のように
3けたごとにカンマが入って見やすくなります。
（`item.price.toLocaleString()` と書いてみよう）

### 課題2-B：在庫の数を出す
```html
<span class="badge bg-success">在庫 <%= ______ %> 個</span>
```

### ✅ 確認
カードに ¥マーク付きの値段と在庫が出て、「詳細を見る」で詳細ページが開けば成功！

> 📸 （ここにカード表示と詳細ページのスクショ）

## Step 3 🛍️ 「カートに入れる」ボタンを完成させよう（穴埋め）

**編集するファイル：`views/partials/product_card.ejs`**（Step2 と同じ共通パーツ）

URL `http://localhost:3000/step3` には「カートに入れる」ボタンがあります。
でも今は **どの商品をカートに入れるか** が決まっていないので動きません。

> ✨ Step2 と同じカードのパーツです。ボタンの部分（`showCart` が `true` のとき出る所）を直すと、
> 本番のお店（`/shop`）の「カートに入れる」ボタンも同時に直ります。

### 課題3：ボタンに「商品番号」を渡す
ボタンのリンク先（`href`）の `______` を埋めよう。

```html
<a href="<%= addUrl %>/<%= ______ %>" class="btn btn-primary w-100">
    <i class="bi bi-cart-plus me-1"></i>カートに入れる
</a>
```
💡ヒント：「どの商品か」を表すのは商品番号 `item.code` です。
（`<%= addUrl %>` の部分は、Step3 では `/cart/add`、本番ショップでは `/shop/add` に
自動で切り替わります。気にしなくてOK！）
これでボタンを押すと「○番の商品をカートに入れて」とサーバーにお願いできます。

### ✅ 確認
ボタンを押して、カート画面（Step4）に商品が入ればOK！

> 📸 （ここにカート追加のスクショ）

## Step 4 🧮 カートを確認して「買う」（穴埋め＋観察）

**編集するファイル：`views/partials/cart_table.ejs`**（カート表の共通パーツ）

URL `http://localhost:3000/step4` はカートの中身を確認して購入する画面です。
「小計（その商品1種類の合計）」を計算して出し、**「購入する」を押すと在庫が減る**のを確かめよう。

> ✨ このカート表のパーツを直すと、本番のお店のカート（`/cart`）も同時に変わります。

### 課題4：小計を計算して出す
```html
<td class="text-end align-middle fw-bold">
    <%= ______ %>円
</td>
```
💡ヒント：小計は「数量 × 値段」。`cart.count`（数量）と `cart.price`（値段）をかけ算します。
`(cart.count * cart.price).toLocaleString()` と書いてみよう。

### ✅ 確認
- カートに商品を入れて、小計と合計が正しく出ればOK！（合計は先生が計算してくれています）
- 「購入する」を押したあと、Step2 のカードで **在庫の数が減っている**ことを確認しよう（10個 → 9個 など）。
  これが「データベースでお店の状態を管理する」仕組み。本物の通販サイトと同じです！

> 📸 （ここにカート画面と、在庫が減った画面のスクショ）

## 🌟 発展課題 — トップページを「自分のお店」にしよう

ここまでで仕組みが分かったね。最後に、**お店のトップページ（`/`）を
自分だけのお店に改造** してみよう！

### 発展A：お店の名前を変える
**ファイル：`views/index.ejs`**
```html
<h1 class="display-4 fw-bold">🛒 翔陽ストアへようこそ</h1>
<p class="fs-5 mb-4">ほしいものが、きっと見つかる。</p>
```
この `翔陽ストア` と キャッチコピーを、自分のお店の名前に変えよう。

**ファイル：`views/partials/header.ejs`**（画面の上のバー）
```html
<a class="navbar-brand" href="/">🛒 翔陽ストア</a>
```
ここの店名も合わせて変えると、全部のページの上に表示されるよ。

### 発展B：売る商品を自分で決める
Step 1 でやったように `db/seed.js` を編集して、
自分のお店で売りたい商品をそろえよう。（5個以上を目指そう！）

### 発展C：友達のお店をのぞいてみよう
同じネットワークなら、友達のサイトを操作したり、
自分のサイトを友達に買い物してもらったりできます（先生の指示に従ってね）。
