# 🛒 ショッピングサイトを作ろう！ ワークシート（生徒用）

ようこそ！ きみは今日、これから **本物そっくりのインターネット通販サイト** を

## 0. じゅんび — まずは動かしてみよう

### サイトを起動する
1. `shop-app` フォルダの中の **`run.bat`** をダブルクリックします。
2. 黒い画面（コマンドプロンプト）が開いて、こんな文字が出たら成功です。
   ```
   ショッピングサイトが起動しました！
   ブラウザで以下のURLを開いてください:
     http://localhost:3000
   ```
3. ブラウザ（Edge や Chrome）を開いて、アドレスバーに
   **`http://localhost:3000`** と入力します。
4. お店のトップページが出てきたら準備かんりょう！🎉

> ⚠️ 黒い画面は **閉じないで** ください。閉じるとお店が止まります。

### コードを編集する（VSCode）
- ファイルは **VSCode** で開いて編集します。
- 直したら **保存（Ctrl + S）** → ブラウザを **更新（F5）** すると、変化が画面に出ます。
- 「編集 → 保存 → ブラウザ更新」。このくり返しが基本です。

### この課題のルール
- 編集するのは、各ステップで指定された **ファイルだけ** です。
- 文章の中の **`______`（下線）** は「**ここに自分で書きこむ場所**」という意味です。
- まちがえても、こわれません。何度でもやり直してOK！

## 🔰 EJS のちょいルール（これだけ覚えればOK）

このサイトの画面は **EJS** という仕組みでできています。覚えるのは2つだけ。

| 書き方 | 意味 | 例 |
|--------|------|-----|
| `<%= ○○ %>` | ○○の中身を **画面に表示する** | `<%= item.name %>` → 商品名が出る |
| `<% ～ %>` | 表示はしないで **計算や条件** をする | `<% if (...) { %>` |

商品データは `item` という箱に入っていて、中身はこうなっています👇

| 書き方 | 出てくるもの |
|--------|------------|
| `item.name` | 商品名（例：ギター） |
| `item.price` | 値段（例：30000） |
| `item.image` | 画像のファイル名（例：guitar） |
| `item.stock` | 在庫の数（例：10） |
| `item.code` | 商品番号（例：1） |

## Step 1 🗂️ データを入れてみよう（商品をふやす・へらす）

**編集するファイル：`db/seed.js`**

このファイルには「お店に最初から並べておく商品」が書いてあります。
今は3つだけです。

```js
db.run(`INSERT INTO item (name, price, image, stock) VALUES ('ギター',       30000, 'guitar',   10)`);
db.run(`INSERT INTO item (name, price, image, stock) VALUES ('キーボード',   48000, 'midi',     10)`);
db.run(`INSERT INTO item (name, price, image, stock) VALUES ('エレクトーン', 300000, 'electone', 10)`);
```

1行が「商品1つ」です。`('商品名', 値段, '画像名', 在庫数)` の順に書きます。

### 課題1-A：商品を1つふやす
下の `______` を自分で決めて、新しい行を **1行追加** しよう。
使える画像名の一覧は、このシートのいちばん下にあります。

```js
db.run(`INSERT INTO item (name, price, image, stock) VALUES ('______', ______, '______', 10)`);
```

### 課題1-B：商品を1つへらす
いらない商品の行を **1行消して** みよう。（行の先頭にカーソル → その行をまるごと削除）

### ✅ 確認のしかた（だいじ）
`seed.js` を変えたら、**`run.bat` をいったん閉じて、もう一度起動**してください。
> このファイルは「最初の1回」だけ読まれます。
> 起動するときに `run.bat` の代わりに **`run_reset.bat`**（先生が用意）を使うと、
> 変えたデータで作り直せます。

トップページ（`/`）や ⚙️商品管理 の画面で、商品がふえた・へったか確認しよう。

## Step 3 🖼️ カードに「値段」と「在庫」を出そう（穴埋め）

**編集するファイル：`views/partials/product_card.ejs`**（商品カードの共通パーツ）

URL `http://localhost:3000/step3` は、商品を大きなカードで並べる画面です。
値段と在庫の部分を完成させよう。

> ✨ **だいじ：** このカードは「共通パーツ」です。ここを直すと、
> Step3 だけでなく **本番のお店（`/shop`）やトップページのカードも同時に変わります**。
> 自分が作った画面が、そのままお店で使われるということ！

### 課題3-A：値段を出す
```html
<p class="card-text text-primary fs-5 fw-bold mb-1">
    ¥<%= ______ %>
</p>
```
💡ヒント：値段は `item.price`。`.toLocaleString()` を後ろに付けると `30,000` のように
3けたごとにカンマが入って見やすくなります。
（`item.price.toLocaleString()` と書いてみよう）

### 課題3-B：在庫の数を出す
```html
<span class="badge bg-success">在庫 <%= ______ %> 個</span>
```

### ✅ 確認
カードに ¥マーク付きの値段と、在庫の数が出れば成功！

> 📸 （ここにカード表示のスクショ）

## Step 4 🛍️ 「カートに入れる」ボタンを完成させよう（穴埋め）

**編集するファイル：`views/partials/product_card.ejs`**（Step3 と同じ共通パーツ）

URL `http://localhost:3000/step4` には「カートに入れる」ボタンがあります。
でも今は **どの商品をカートに入れるか** が決まっていないので動きません。

> ✨ Step3 と同じカードのパーツです。ボタンの部分（`showCart` が `true` のとき出る所）を直すと、
> 本番のお店（`/shop`）の「カートに入れる」ボタンも同時に直ります。

### 課題4：ボタンに「商品番号」をわたす
ボタンのリンク先（`href`）の `______` を埋めよう。

```html
<a href="<%= addUrl %>/<%= ______ %>" class="btn btn-primary w-100">
    <i class="bi bi-cart-plus me-1"></i>カートに入れる
</a>
```
💡ヒント：「どの商品か」を表すのは商品番号 `item.code` です。
（`<%= addUrl %>` の部分は、Step4 では `/cart/add`、本番ショップでは `/shop/add` に
自動で切りかわります。気にしなくてOK！）
これでボタンを押すと「○番の商品をカートに入れて」とサーバーにお願いできます。

### ✅ 確認
ボタンを押して、カート画面に商品が入ればOK！

> 📸 （ここにカート追加のスクショ）

## Step 5 🧮 カートの「小計」と「合計」を出そう（穴埋め）

**編集するファイル：`views/partials/cart_table.ejs`**（カート表の共通パーツ）

URL `http://localhost:3000/step5` はカートの中身を見る画面です。
「小計（その商品1種類の合計）」を計算して出そう。

> ✨ このカート表のパーツを直すと、本番のお店のカート（`/cart`）も同時に変わります。

### 課題5：小計を計算して出す
```html
<td class="text-end align-middle fw-bold">
    <%= ______ %>円
</td>
```
💡ヒント：小計は「数量 × 値段」。`cart.count`（数量）と `cart.price`（値段）をかけ算します。
`(cart.count * cart.price).toLocaleString()` と書いてみよう。

### ✅ 確認
カートに商品を入れて、小計と合計が正しく出ればOK！
（合計は先生があらかじめ計算してくれています）

## 🌟 発展課題 — トップページを「自分のお店」にしよう

ここまでで仕組みがわかったね。さいごに、**お店のトップページ（`/`）を
自分だけのお店に改造** してみよう！

### 発展A：お店の名前を変える
**ファイル：`views/index.ejs`**
```html
<h1 class="display-4 fw-bold">🛒 翔陽ストアへようこそ</h1>
<p class="fs-5 mb-4">ほしいものが、きっと見つかる。</p>
```
この `翔陽ストア` と キャッチコピーを、自分のお店の名前に変えよう。

**ファイル：`views/partials/header.ejs`**（画面の上のバー）
```html
<a class="navbar-brand" href="/">🛒 翔陽ストア</a>
```
ここの店名も合わせて変えると、全部のページの上に表示されるよ。

### 発展B：売る商品を自分で決める
Step 1 でやったように `db/seed.js` を編集して、
自分のお店で売りたい商品をそろえよう。（5個以上をめざそう！）

### 発展C：友だちのお店をのぞいてみよう
同じネットワークなら、友だちのサイトを操作したり、
自分のサイトを友だちに買い物してもらったりできます（先生の指示にしたがってね）。
