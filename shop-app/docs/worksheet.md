# 🛒 ショッピングサイトを作ろう！ ワークシート

ようこそ！ 皆さんは今日、これから **本物そっくりのインターネット通販サイト** を
自分の手で完成させていきます。

難しいプログラムは、ほとんど先生が用意してあります。
皆さんがやるのは「**画面に何を出すか**」を決めている部分を、自分で書き込むことです。

> 📸 （ここに完成イメージのスクリーンショットを入れる）

## 0. 準備 — まずは動かしてみよう

### サイトを起動する
1. `shop-app` フォルダの中の **`run.bat`** をダブルクリックします。
2. 黒い画面（コマンドプロンプト）が開いて、こんな文字が出たら成功です。
   ```
   ショッピングサイトが起動しました！
   ブラウザで以下のURLを開いてください:
     http://localhost:3000
   ```
3. ブラウザ（Edge や Chrome）を開いて、アドレスバーに
   **`http://localhost:3000`** と入力します。
4. お店のトップページが出てきたら準備完了！🎉

> ⚠️ 黒い画面は **閉じないで** ください。閉じるとお店が止まります。

### コードを編集する（VSCode）
- ファイルは **VSCode** で開いて編集します。
- 直したら **保存（Ctrl + S）** → ブラウザを **更新（F5）** すると、変化が画面に出ます。
- 「編集 → 保存 → ブラウザ更新」。この繰り返しが基本です。

### この課題のルール
- 編集するのは、各ステップで指定された **ファイルだけ** です。
- コードの中の **`'dummy'`** や **`______`** は「**ここに自分で書き込む場所**」という意味です。
  画面に「**dummy**」と出ていたり、絵が「**こわれた絵**」になっていたら、まだ完成していない印だよ。
- 間違えても、壊れません。何度でもやり直してOK！

## 🔰 EJS の基本ルール（これだけ覚えればOK）

このサイトの画面は **EJS** という仕組みでできています。覚えるのは2つだけ。

| 書き方 | 意味 | 例 |
|--------|------|-----|
| `<%= ○○ %>` | ○○の中身を **画面に表示する** | `<%= item.name %>` → 商品名が出る |
| `<% ～ %>` | 表示はしないで **計算や条件** をする | `<% if (...) { %>` |

商品データは `item` という箱に入っていて、中身はこうなっています👇

| 書き方 | 出てくるもの |
|--------|------------|
| `item.name` | 商品名（例：ギター） |
| `item.price` | 値段（例：30000） |
| `item.image` | 画像のファイル名（例：guitar） |
| `item.stock` | 在庫の数（例：10） |
| `item.code` | 商品番号（例：1） |
| `item.description` | 商品の説明文（詳細ページに出る） |

## Step 1 🗂️ 商品を登録しよう（増やす・減らす）

お店に並べる商品を登録します。やり方は2つ。

### やり方① 管理画面のフォームから
URL `http://localhost:3000/step1`（ナビの ⚙️商品管理）を開きます。
左のフォームに **商品名・価格・画像・商品説明** を入れて「追加する」を押すと、
すぐに商品が増えます。要らない商品は右の一覧の 🗑️ で消せます。

### やり方② コードで最初の品ぞろえを決める（`db/seed.js`）
**編集するファイル：`db/seed.js`**

このファイルには「お店に最初から並べておく商品」が書いてあります。今は3つです。

```js
db.run(`INSERT INTO item (name, price, image, stock, description) VALUES ('ギター', 30000, 'guitar', 10, '初心者にもやさしいギター。')`);
```

1行が「商品1つ」です。`('商品名', 値段, '画像名', 在庫数, '説明文')` の順に書きます。

#### 課題1-A：商品を1つ増やす
下の `______` を自分で決めて、新しい行を **1行追加** しよう。
使える画像名の一覧は、このシートの一番下にあります。

```js
db.run(`INSERT INTO item (name, price, image, stock, description) VALUES ('______', ______, '______', 10, '______')`);
```

#### 課題1-B：商品を1つ減らす
要らない商品の行を **1行消して** みよう。（行の先頭にカーソル → その行をまるごと削除）

### ✅ 確認の仕方（大事）
`seed.js` を変えたら、**`run.bat` をいったん閉じて、`run_reset.bat`（先生が用意）で起動し直す**と、
変えたデータで作り直せます。
> `seed.js` は「最初の1回」だけ読まれるので、普通の `run.bat` では反映されません。
> （フォームからの追加は、その場ですぐ反映されます。）

トップページ（`/`）や ⚙️商品管理 の画面で、商品が増えた・減ったか確認しよう。

## Step 3 🛍️ 「カートに入れる」ボタンを完成させよう（穴埋め）

**編集するファイル：`views/mikansei/product_card.ejs`**（Step2 と同じ共通パーツ）

URL `http://localhost:3000/step3` には「カートに入れる」ボタンがあります。
でも今は **行き先も・どの商品か・色も** 決まっていないので、押しても動きません（色もついていません）。
このボタンを3つの穴埋めで完成させよう。

> ✨ Step2 と同じカードのパーツです。ボタンの部分（`showCart` が `true` のとき出る所）を直すと、
> 本番のお店（`/shop`）の「カートに入れる」ボタンも同時に直ります。

完成させるのは、この1行の中にある **3つの `'dummy'`** です👇
```html
<a href="<%= 'dummy' %>/<%= 'dummy' %>" class="btn <%= 'dummy' %> w-100">
    <i class="bi bi-cart-plus me-1"></i>カートに入れる
</a>
```

### 課題3-A：ボタンの「行き先」を入れる（1つ目の `'dummy'`）
1つ目の `'dummy'` を `addurl` に書きかえよう（クォート `' '` は付けない）。
```html
<a href="<%= addurl %>/<%= 'dummy' %>" ...>
```
💡ヒント：カートに入れるときの行き先（URL）は `addurl` という箱に入っています。
これは Step3 では `/cart/add`、本番ショップでは `/shop/add` に **自動で切り替わります**。
だから皆さんは `addurl` と書くだけでOK！

### 課題3-B：どの商品かを渡す（2つ目の `'dummy'`）
2つ目の `'dummy'` を商品番号 `item.code` に書きかえよう。
```html
<a href="<%= addurl %>/<%= item.code %>" ...>
```
💡ヒント：これでリンク先が `/cart/add/3` のようになり、「○番の商品をカートに入れて」と
サーバーにお願いできます。

### 課題3-C：ボタンの色を決める（3つ目の `'dummy'`）
3つ目の `'dummy'`（`class="btn ..."` の中）を、好きな色のクラスに書きかえよう。
```html
<a ... class="btn btn-primary w-100">
```
💡ヒント：色は **クラス名** で決まります。`btn-primary`＝青 / `btn-success`＝緑 /
`btn-danger`＝赤 / `btn-warning`＝黄。`'dummy'` のままだと色のつかない地味なボタンのままだよ。

### ✅ 確認
ボタンに色がついて、押すとカート画面（Step4）に商品が入ればOK！

## Step 4 🧮 カートを確認して「買う」（穴埋め＋プログラム）

**編集するファイル：`views/mikansei/cart_table.ejs`（カート表）、`views/mikansei/buy_button.ejs`（購入ボタン）、`db/database.js`（お店の頭脳）**

URL `http://localhost:3000/step4` はカートの中身を確認して購入する画面です。
「小計（その商品1種類の合計）」を計算して出し、**「購入する」ボタンを完成させ**、
さらに **「購入したら在庫を減らす」プログラム** を完成させよう。

> ✨ このカート表のパーツを直すと、本番のお店のカート（`/cart`）も同時に変わります。

### 課題4-A：小計を計算して出す（画面）
**ファイル：`views/mikansei/cart_table.ejs`**
```html
<td class="text-end align-middle fw-bold">
    <%= 'dummy' %>円
</td>
```
💡ヒント：小計は「数量 × 値段」。`cart.count`（数量）と `cart.price`（値段）をかけ算します。
`(cart.count * cart.price).toLocaleString()` と書いてみよう。

### 課題4-B：「購入する」ボタンの送信先を入れる（画面）
**ファイル：`views/mikansei/buy_button.ejs`**

「購入する」ボタンも、今は **送信先が決まっていない** ので押しても買えません。
`form` の `action` の `'dummy'` を `buyurl` に書きかえよう（クォート `' '` は付けない）。
```html
<form action="<%= buyurl %>" method="POST">
```
💡ヒント：送信先は `buyurl` という箱に入っています。Step4 では `/purchase`、本番ショップの
カートでは `/buy` に **自動で切り替わります**。だから皆さんは `buyurl` と書くだけでOK！
`'dummy'` のままだと、押しても「買えない（404 エラー）」になります。

> ✨ この購入ボタンも共通パーツです。直すと、本番ショップのカート（`/cart`）の
> 「購入する」ボタンも同時に直ります。

### 課題4-C：「購入する」ボタンの色を決める（画面）
**ファイル：`views/mikansei/buy_button.ejs`**

ボタンの色のクラス `'dummy'` を、目立つ色に書きかえよう。
```html
<button type="submit" class="btn btn-danger btn-lg px-5" ...>
```
💡ヒント：`btn-danger`＝赤 / `btn-primary`＝青 / `btn-success`＝緑。
「買う」ボタンは目立つ色がおすすめです。

### 課題4-D：在庫を減らすプログラムを完成させる（本物のプログラム！）
**ファイル：`db/database.js`**

ここまでは「画面に何を出すか」を書いてきました。最後は **お店の頭脳** の部分。
「購入する」を押したとき、**買った数だけ在庫を減らす計算** を自分で書きます。

`purchase()`（購入処理）の中に、こんな行があります👇
```js
// 新しい在庫 ＝ 今の在庫 − 買った数
const newStock = item.stock;   // ← 今は「今の在庫」のままなので、在庫が減らない！
```
この `item.stock` の部分を、**「今の在庫 − 買った数」** に書きかえよう。
```js
const newStock = item.stock - item.count;
```
💡ヒント：
- `item.stock` … 今の在庫の数
- `item.count` … カートに入っている（買う）数
- ひき算は記号 `-`（マイナス）を使います。

これで「○個買ったから、在庫を○個減らしてね」とデータベースにお願いできます。

### ✅ 確認
- カートに商品を入れて、小計と合計が正しく出ればOK！（合計は先生が計算してくれています）
- 課題4-B を直すと「購入する」ボタンが効くようになり、色（4-C）もつきます。
- 課題4-D を **直す前** は、「購入する」を押しても **在庫が減りません**（ずっと10個のまま）。
- 課題4-D を **直したあと** は、「購入する」を押すと Step2 のカードで **在庫の数が減ります**（10個 → 9個 など）。
  自分が書いた計算で、お店の在庫が本当に動く！ これが「データベースでお店の状態を管理する」仕組み。本物の通販サイトと同じです！

> ⚠️ `db/database.js` を直したら、**`run.bat` をいったん閉じて開き直す**と確実に反映されます。

### 発展D：ナビ（上のバー）の色を変えよう
**ファイル：`views/mikansei/header.ejs`**（画面の上のバー）

お店のいちばん上にある黒いバー（ナビ）の **背景の色** と **文字の色** を、
自分好みの色に変えてみよう。色は **クラス名** を書きかえるだけで変わります（CSSは書かなくてOK）。

今はこうなっています👇
```html
<nav class="navbar navbar-expand-lg navbar-dark bg-dark">
```

- **背景の色** … `bg-dark` の部分を `bg-○○` に変える。
- **文字の色** … `navbar-dark`（白っぽい字）か `navbar-light`（黒っぽい字）で切りかえる。
  背景が明るい色のときは `navbar-light` にすると文字が見えやすいよ。

たとえば「黄色の背景＋黒い文字」にするなら👇
```html
<nav class="navbar navbar-expand-lg navbar-light bg-warning">
```

💡 使える色クラス（背景は `bg-○○`、文字は各リンクの `text-○○`）：

| 色クラス（○○の部分） | だいたいの色 |
|------|------|
| `primary` | 青 |
| `secondary` | 灰 |
| `success` | 緑 |
| `danger` | 赤 |
| `warning` | 黄 |
| `info` | 水色 |
| `light` | 白に近い薄灰 |
| `dark` | 黒に近い濃灰 |

文字を1つずつ派手な色にしたいときは、メニューのリンクに `text-○○` を足してもOK👇
```html
<a class="nav-link text-danger" href="/">🏠 Home</a>
```

> 💡 もっと奇抜な色（蛍光ピンクなど）にしたい人は、`public/css/styles.css` の
> いちばん下に `.navbar { background-color: #ff00cc !important; }` のように
> 自分で色を書く方法もあるよ（先生に聞いてみよう）。
