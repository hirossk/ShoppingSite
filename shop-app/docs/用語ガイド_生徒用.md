# 📖 用語ガイド（生徒用）— わからない言葉が出てきたら

ワークシートをやっていて「これ何？」と思ったら、ここを見てね。
むずかしい説明はぬきにして、イメージでわかるように書いてあります。

---

## 🌐 サイトが動くしくみ（ざっくり）

```
   きみ                サーバー                  データベース
（ブラウザ）  ←→   （お店の店員さん）   ←→   （商品台帳ノート）
  画面を見る        どの画面を出すか考える       商品や在庫を覚えておく
```

- **ブラウザ**：画面を見る道具（Edge・Chrome など）。
- **サーバー**：「この商品を出して」とお願いを受けて、画面を作って返す係。
  `run.bat` の黒い画面で動いているのがサーバー。
- **データベース**：商品名・値段・在庫・カートを覚えておくノート。このサイトでは `shop.db`。

---

## 🏷️ EJS の記号

このサイトの画面（`.ejs` ファイル）でいちばん大事な2つ。

| 記号 | よみ・意味 | 例 |
|------|-----------|-----|
| `<%= ○○ %>` | 「○○を**画面に出す**」 | `<%= item.name %>` → 商品名が出る |
| `<% ～ %>` | 「**計算や条件**（画面には出さない）」 | `<% if (item.stock > 0) { %>` |

> `=` が付くと「**出す**」、付かないと「**裏で考える**」とおぼえよう。

---

## 📦 `item`（商品の箱）の中身

商品1つの情報は `item` という箱に入っています。

| 書き方 | 中身 | 例 |
|--------|------|-----|
| `item.code` | 商品番号 | 1 |
| `item.name` | 商品名 | ギター |
| `item.price` | 値段 | 30000 |
| `item.image` | 画像のファイル名 | guitar |
| `item.stock` | 在庫の数 | 10 |

カートの中身は `cart` という箱で、`cart.count`（数量）も使えます。

---

## 🖼️ 画像の出し方

画像は `public/images/` フォルダに入っています（例：`guitar.png`）。
画面に出すときは、こう書きます👇

```html
<img src="/images/guitar.png">
```

商品ごとに変えたいときは、ファイル名のところを `<%= item.image %>` にします。

```html
<img src="/images/<%= item.image %>.png">
```
→ `guitar` の商品なら `/images/guitar.png`、`piano` の商品なら `/images/piano.png` になる。

## 🔤 よく出てくる言葉じてん

| 言葉 | 意味 |
|------|------|
| **seed（シード）** | 「種」。お店に最初から並べる商品データのこと（`db/seed.js`）。 |
| **データベース / DB** | 商品や在庫を覚えておくノート。`shop.db`。 |
| **在庫（stock）** | その商品の残りの数。買うと減る。0になると「売り切れ」。 |
| **カート（cart）** | 買い物かご。買う前に商品を入れておくところ。 |
| **コード（code）** | 商品につけられた番号。どの商品かを区別するのに使う。 |
| **ルート（route）** | URL（例：`/shop`）と、出てくる画面のセット。`routes/shop.js` で決めている。 |
| **`toLocaleString()`** | 数字を `30,000` のようにカンマ区切りで見やすくするおまじない。 |
| **`forEach`（フォーイーチ）** | 「全部の商品について、くり返し同じことをする」命令。一覧表示に使う。 |
| **POST / GET** | サーバーへのお願いの種類。GET＝見せて、POST＝送る（追加・購入など）。 |
| **サーバーを起動** | `run.bat` でお店を動かし始めること。黒い画面が出る。 |

## 🔁 編集のながれ（こまったとき用）

1. **VSCode** でファイルを開く
2. `______` を自分で書きこむ
3. **保存**（Ctrl + S）← わすれやすい！
4. ブラウザを **更新**（F5）
5. 変わっていなかったら → 「保存したか」「黒い画面は開いているか」を確認

---

## 🆘 よくあるトラブル

| こまったこと | どうする |
|--------------|---------|
| 画像が出ない（枠だけ） | 画像の名前があっているか確認（拡張子 `.png` はそのまま、名前だけ変える）。 |
| 変えたのに画面が同じ | 保存した？ ブラウザを F5 で更新した？ |
| `seed.js` の商品が増えない | `run.bat` を閉じて **`run_reset.bat`** で起動し直す。 |
| 画面が真っ白になった | 直前に消しすぎたかも。`<% %>` のカッコを消していないか確認。 |

それでもダメなら、遠りょなく先生を呼んでね！ 🙋
